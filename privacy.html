Privacy notice

Last updated: October 25, 2026

AI Home Hub Backup is a personal backup utility operated by its sole user. This notice describes the intended setup; cloud backup verification is still in progress.

Purpose and access

The app uses Google Drive only to store, read and manage encrypted backup repository files and verify recovery. It requests drive.file, limited to files it creates or that the owner explicitly makes available to it. It does not request full Drive, Gmail or Contacts access.

Data used and stored

Selected backup content is encrypted locally with Restic before transfer. Google Drive receives encrypted repository objects and associated file metadata, such as object names, sizes and modification times. The app uses file identifiers and storage-quota information to manage backups. Google also processes normal account and connection metadata for its service.

OAuth credentials are stored in a restricted configuration on the owner's computer. Backup decryption passwords remain separately controlled by the owner. Neither credentials nor backup files are collected by this website. Local operational records may contain backup identifiers, counts, times and failure information.

Use and sharing

Backup data is used for storage, verification and recovery. The app does not sell Google user data or use it for advertising, analytics or AI model training. Encrypted files are transferred to the owner's Google Drive; restoring them returns them to owner-controlled storage. The app does not publish backup files or give other users access.

Retention and control

The owner controls backup retention and deletion. Revoking the app in Google Account connections stops future access but does not itself delete existing backup files. Those files can be removed separately in Drive. Deleting backups may remove recovery options.

This website

These static pages contain no forms, analytics scripts or app cookies. The host, GitHub Pages, records visitor IP addresses for security; its privacy statement explains the host's handling. Visiting these pages does not authorize the backup app.

Operator and changes

This app is administered by its sole user. The operator's support address appears on Google's consent screen. The notice will be updated before the app uses data for a materially different purpose or requests additional access.
